
# Khula - Your Business. Your Growth. Your Future!

## Overview
Khula is an offline-first business management application
designed to empower township and rural entrepreneurs
in South Africa.

The application aims to help small business owners
manage sales, expenses, inventory, and cash flow
using simple and accessible digital tools.

## Problem Statement
Many township and rural entrepreneurs struggle with
manual record-keeping, financial management,
inventory tracking, and unreliable internet access.

Khula aims to address these challenges through
an affordable, user-friendly business management system.

## Planned MVP Features
- Business dashboard
- Sales recording and tracking
- Expense management
- Inventory management
- Profit and revenue summaries
- Offline data storage using SQLite

## Technology Stack
- Python 3.13
- Kivy 2.3.1
- SQLite
- Git and GitHub
- Visual Studio Code

## Current Development Status
Phase 1: Initial project setup completed.

The first Khula application window has been
successfully launched.

Core business management features are under development.

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Create a Python 3.13 virtual environment.
4. Activate the virtual environment.
5. Install Kivy:

   python -m pip install "kivy[base]==2.3.1"

6. Run the application:

   python main.py
